# VESCDISPLAY

Projekt Android Studio w Kotlinie i Jetpack Compose. Otwórz folder android-module jako projekt w Android Studio.

## Uruchomienie

1. Sklonuj repozytorium lub pobierz jego pliki.
2. W Android Studio wybierz Open i wskaż folder android-module.
3. Poczekaj na synchronizację Gradle, potem uruchom konfigurację app na emulatorze lub urządzeniu.

Aplikacja uruchamia ekran „Jazda na żywo” w trybie offline. To repozytorium nie zawiera kodu Bluetooth BLE ani dekodera protokołu VESC z istniejącej aplikacji, więc nie pokazuje fikcyjnych odczytów i nie wysyła poleceń do sterownika. Instrukcja podłączenia istniejącego źródła RT Data znajduje się w android-module/INTEGRACJA_JAZDA_NA_ZYWO.md.
